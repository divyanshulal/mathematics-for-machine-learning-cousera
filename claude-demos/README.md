# Claude Demos - Mathematics for Machine Learning

This directory contains practical Python demonstrations of key concepts from the Mathematics for Machine Learning specialization.

## Contents

1. **linear_algebra_demo.py** - Matrix operations, eigenvalues, linear transformations
2. **gradient_descent_demo.py** - Optimization using calculus concepts
3. **pca_demo.py** - Principal Component Analysis implementation
4. **neural_network_math_demo.py** - Putting it all together in a simple neural network

## Requirements

```bash
pip install numpy matplotlib scikit-learn
```

## Usage

Each demo can be run independently:

```bash
python linear_algebra_demo.py
python gradient_descent_demo.py
python pca_demo.py
python neural_network_math_demo.py
```

## Learning Objectives

These demos illustrate practical applications of:
- Linear transformations and matrix operations
- Eigenvalues and eigenvectors
- Gradient descent and optimization
- Dimensionality reduction with PCA
- Backpropagation and neural networks
